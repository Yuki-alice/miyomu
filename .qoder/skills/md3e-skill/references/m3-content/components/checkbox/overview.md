# Checkbox

> Checkboxes let users select one or more items from a list, or turn an item on or off

-   Use checkboxes (instead of switches Switches toggle the state of an item on or off. [More on switches](/m3/pages/switch/overview) or radio buttons Radio buttons let people select one option from a set of options. [More on radio buttons](/m3/pages/radio-button/overview) ) if multiple options can be selected from a list Lists are continuous, vertical indexes of text and images. [More on lists](/m3/pages/lists/overview)
-   Label should be scannable
-   Selected items are more prominent than unselected items
