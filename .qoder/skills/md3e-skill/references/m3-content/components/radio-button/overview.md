# Radio button

> Radio buttons let people select one option from a set of options

-   Use radio buttons (not switches Switches toggle the state of an item on or off. [More on switches](/m3/pages/switch/overview) ) when only one item can be selected from a list Lists are continuous, vertical indexes of text and images. [More on lists](/m3/pages/lists/overview)
-   Label should be scannable
-   Selected items are more prominent than unselected items
