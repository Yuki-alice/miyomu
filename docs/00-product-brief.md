# 产品简报

> 状态：草案 · 2026-10-28
> 项目名：**Miyomu**（2026-10-28 确认；不设独立中文名，详见 [品牌备忘](06-brand.md)）

## 一句话

一个跨平台应用，把漫画、小说、视频放进同一个库，用同一套源扩展协议连接内容，用同一套进度与下载体系管理消费。

## 问题与机会

现有开源方案各有明显缺口：

- **Aniyomi**：Android 端体验成熟，扩展生态庞大；但维护近乎停滞（近一年 21 次提交、361 个未关 issue），仅 Android，扩展模型是 Android-only 的 APK。
- **Venera-Next**：跨平台、JS 源、发布工程完善；但只做漫画，原版作者已停止维护，续作是单人项目，且 GPL-3.0。
- **Mihon/Tachiyomi 系**：漫画体验优秀，但无视频/小说，跨平台缺位。
- **通用阅读器**：本地格式支持好，但没有统一的源扩展与跨媒介库。

机会点不是"再做一个阅读器"，而是**统一数据与源协议，按媒介提供专业界面**：一个库、三种消费方式、可移植的 JS 源、Android 级完成度。

## 目标用户

1. 同时看漫画、小说、动画的重度用户，内容来自自建源、本地文件或 NAS/WebDAV。
2. 从 Aniyomi 迁移、希望桌面端也能连续阅读的用户。
3. 愿意自己编写或导入 JS 源的高级用户。

## 价值主张

- **一个库**：收藏、历史、进度、下载、聚合搜索跨媒介统一。
- **跨平台一致**：Android、Windows、macOS、Linux 首发；iOS 后续。
- **源可移植**：JS 源一次编写，全平台运行；兼容 Venera 漫画源格式（清洁实现）。
- **Aniyomi 级体验**：沿用其信息架构与阅读器交互习惯，而不是另造一套。
- **本地优先**：本地文件、WebDAV 与离线下载是一等公民，不依赖任何在线服务。

## v1 范围（提议）

| 能力 | v1 | 后续 |
|---|---|---|
| 平台 | Android、Windows、macOS、Linux | iOS |
| 漫画 | 在线阅读、下载、本地导入（CBZ/ZIP/7Z/PDF） | RAR、更多格式 |
| 小说 | TXT/EPUB、排版、进度 | 在线书源、TTS |
| 视频 | mediamp 播放、外挂字幕、续播 | 投屏、直播、BT |
| 源 | JS 运行时、Venera 兼容子集、用户添加仓库 | 视频源 hoster 扩展 |
| 库 | 收藏、历史、分类、聚合搜索 | 智能推荐 |
| 同步 | WebDAV（库、进度、设置） | 自建同步服务 |
| 追踪 | 无 | MAL/AniList/Bangumi 等 |
| 分发 | GitHub Releases / 侧载 | 应用商店（取决于平台与许可） |

### 非目标

- 不内置、不推荐、不托管任何内容源或内容。
- 不做 DRM 绕过、破解或付费内容获取。
- v1 不做投屏、BT/种子、直播、社交、评论聚合。
- v1 不做 App Store 上架；GPL/内容合规风险单独评估。
- 不做"万能渲染器"；三种媒介的界面保持独立。

## 产品原则

1. **统一的是数据与源，不是界面**。库、进度、下载、同步、搜索共享；阅读器/播放器各自专业化。
2. **本地优先、离线可用**。任何在线能力失效时，本地库仍然完整可用。
3. **源是插件，不是内核**。宿主只暴露受控能力；扩展不能直接触碰文件系统与网络栈。
4. **持续可发布**。每个阶段都要有可安装产物，禁止 6 个月以上的"重写黑洞"。
5. **清洁实现**。Aniyomi（Apache-2.0）可复用；Venera（GPL-3.0）只参考行为，不复制代码。
6. **隐私默认**。无遥测、无账号体系；崩溃上报需显式开启。
7. **设计服务于内容**。动效与 MD3E 是加分项，不牺牲启动速度、滚动帧率与阅读沉浸感。

## 成功标准

### Phase 0（验证）

- S1/S2/S3 三个 Spike 达到各自规格中的通过标准。
- 产出可复核的报告与功能矩阵，而不是"感觉能用"。

### v1（产品）

- Android 与至少一个桌面平台可日常使用：导入 → 找书 → 阅读/观看 → 下载 → 同步闭环。
- 一个真实 Venera 兼容漫画源可在 Android + 桌面运行，无需修改源脚本。
- 大库场景（1,000 部作品、10,000 章节）冷启动与滚动无明显卡顿。
- 迁移期间 Android 版本保持可发布，不出现数据丢失。

## 约束与假设

- 团队规模：单人全职或 2–3 人小团队（待确认）。
- 技术基线：Kotlin 2.4.x、Compose Multiplatform 1.12.x、Gradle 9.4.x、JDK 21。
- 代码许可：Apache-2.0（2026-10-28 确认）；不引入 GPL 代码。
- 品牌与包名独立，不沿用 Aniyomi 商标与图标。
- 网络源合规风险由使用者承担；产品不提供源列表。

## Phase 0 结果（2026-10-28）

**决策：Go（缩范围）** —— Android + 桌面首发；iOS 后置；音轨选择、Ktor 网络层、Cookie 持久化为 Phase 1 必做。详见 [Phase 1 计划](05-phase-1-plan.md)。

- S1：桌面 + Android 播放/字幕/seek/50 seek/30min 墙钟通过；iOS 裸测试宿主无法驱动 AVKit；统一 API 缺音轨/内嵌字幕选择。
- S2：JVM/Android/iOS 的 JSON+HTML 源、DOM、Cookie、并发与超时通过；Ktor/持久化/源仓库待 Phase 1。
- S3：CMP 三屏 headless 截图与 1,000 项滚动通过；MD3E 依赖 alpha artifact。
- 工具链：Phase 1 M0 已收敛为 AGP 9.4.1 + KGP/编译器 2.3.21 单轨，可直接读取 quickjs-kt 的 Kotlin 2.4 元数据（[ADR-0006](adr/0006-unified-android-toolchain.md)）。
