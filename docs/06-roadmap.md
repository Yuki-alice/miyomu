# 06 · 路线图

> **方向修正（2026-10-31）：** 本文为初稿，部分结论已被 [07-架构优先方案](07-architecture-first.md) 与 [08-MD3E 设计系统](08-md3e-design.md) 取代。冲突处以后两者为准。

> **按 07 的修正：** 阶段改为架构迁移 P0–P6 + 设计并行 D0–D5；时间与验收以 07 为准。本文的指标/门禁可继续参考。

> 从“能跑”到“愿意每天用”，再到“跨平台可用”。
> 每个里程碑只承诺一条完整用户路径；不在里程碑内并行铺新功能。

## 1. 总览

```text
M0 骨架        M1 纵切         M2 日常可用      M3 阅读器/桌面    M4 生态          M5 跨端/发布
1–2 周    →    4–5 周     →    4–5 周      →    4–5 周      →    6–8 周     →    5–6 周
三端 hello     导入源→阅读      书库/下载/更新    双页/RTL/键鼠     Mihon/小说/视频   WebDAV/iOS/v1.0
```

| 里程碑 | 目标 | 预计 | 关键产出 |
| --- | --- | ---: | --- |
| **M0 Foundation** | 三端骨架、设计系统、CI | 1–2 周 | 可运行的 App 壳 |
| **M1 Vertical Slice** | 一个源、一条阅读闭环 | 4–5 周 | v0.1 |
| **M2 Daily Driver** | 书库/历史/更新/下载/备份 | 4–5 周 | v0.5 |
| **M3 Reader & Desktop** | 阅读器完善、桌面一等公民 | 4–5 周 | v0.7 |
| **M4 Ecosystem** | Mihon/Aniyomi、小说、视频 | 6–8 周 | v0.9 |
| **M5 Cross-platform & Release** | WebDAV、iOS、发布 | 5–6 周 | v1.0 |

## 2. M0 · Foundation（1–2 周）

### 范围

- Gradle 多模块 + convention plugins
- `:app:shared` 的 `App()` 在三端显示
- Sumi 设计 token + 基础组件
- 自适应壳（底栏/rail/sidebar）
- SQLDelight 空库 + 迁移测试
- Koin 装配
- CI 三端 job
- 文档/ADR/许可证

### 退出条件

- [ ] Android 模拟器、Desktop 窗口、iOS 模拟器显示同一页面。
- [ ] 改变窗口宽度，导航从底栏切到 sidebar。
- [ ] `./gradlew check` 绿。
- [ ] CI 三端绿。
- [ ] 冷启动 < 2s（debug 可放宽）。

### 风险

- 三端工具链同时配置容易卡在 Gradle/Kotlin/Native；先 Android + Desktop，iOS 只做 framework 链接，再补 Xcode。

## 3. M1 · Vertical Slice（4–5 周）

### 用户路径

> 导入一个原生 JSON 源 → 浏览/搜索 → 打开详情 → 收藏 → 阅读 3 章 → 退出重进恢复位置。

### 范围

- `SourceRuntime` + `SourceRegistry` + 原生 manifest 引擎
- 1 个 fixture 源 + 1 个真实源
- Browse / Source results / Search / Details
- Library（收藏）+ History + 进度
- 单页 / 条漫 / 纵向阅读
- 基础设置/主题
- Android + Desktop

### 退出条件

- [ ] 导入源不需要重启。
- [ ] 浏览分页、搜索、详情、章节列表可用。
- [ ] 收藏后在书库出现。
- [ ] 阅读进度退出/重启后恢复。
- [ ] 单页/条漫切换正确。
- [ ] 10k 书库列表不加载章节（查询计数）。
- [ ] 三端 UI 代码共享率 > 80%（feature 层）。

### 不做

- 下载、更新、扩展、小说、视频、同步。

## 4. M2 · Daily Driver（4–5 周）

### 范围

- 书库筛选/排序/分类/多选
- 更新检测 + Updates 时间轴 + 红点
- 下载队列 + 离线 + CBZ 导出
- 设置页（源管理、阅读、外观、存储）
- 备份/恢复（自有 v1）
- 源测试/诊断
- 通知
- 小说导入（EPUB/TXT）+ 基础阅读
- Android + Desktop

### 退出条件

- [ ] 断网可读已下载章节。
- [ ] 更新事件按“发现时间/已查看/已读完”正确工作。
- [ ] 备份导出→清库→恢复，收藏/历史/进度/分类完整。
- [ ] 10k 书库滚动稳定；无 N+1。
- [ ] 下载暂停/继续/重启恢复。
- [ ] 存储预算可配置并生效。

## 5. M3 · Reader & Desktop（4–5 周）

### 范围

- 双页/RTL/横向连续/裁边/宽图独占
- 预取窗口 + 大图分块 + 内存预算
- 阅读器 chrome/选项/章节目录/书签
- 桌面快捷键、命令面板、右键菜单、窗口状态
- 平板/折叠双栏
- 阅读器性能基准
- 桌面打包（DMG/MSI/deb）

### 退出条件

- [ ] 双页/RTL 在平板与桌面正确。
- [ ] 长条漫 20,000px 页面不 OOM。
- [ ] 翻页稳定 60fps；预取命中 > 80%。
- [ ] 键盘可完成“打开→翻页→跳章→退出”。
- [ ] 桌面安装包可启动。

## 6. M4 · Ecosystem（6–8 周）

### 范围

- Android Mihon APK 扩展（加载/仓库/安装/启用/偏好）
- Desktop JVM 宿主（JAR/APK 转换、独立进程）
- Aniyomi（视频）基础
- TVBox/CMS 原生源
- 视频播放器（Media3/libmpv/AVPlayer 抽象）
- 小说阅读器完善
- 扩展管理 UI/源测试

### 退出条件

- [ ] Android 安装 Mihon 扩展后可浏览/阅读。
- [ ] Desktop 宿主可加载同一扩展；崩溃不拖垮主进程。
- [ ] TVBox/CMS 源可浏览/播放。
- [ ] 视频 HLS/MP4 播放、字幕/音轨切换。
- [ ] 小说章节阅读/进度/书签。

### 风险

- 扩展 ABI/兼容层/许可证；先做最小可用，不追求全生态。
- 视频解码/打包体积；先平台原生，不做超分。

## 7. M5 · Cross-platform & Release（5–6 周）

### 范围

- WebDAV 同步（上传/下载/合并/保留/自动）
- iOS Compose App（原生源、本地内容、阅读、备份）
- 三端 UI 一致性打磨
- 无障碍/本地化
- 性能/稳定性门禁
- 发布流水线（APK/DMG/MSI/deb/IPA）
- 文档/隐私政策/免责声明

### 退出条件

- [ ] 两台设备通过 WebDAV 同步收藏/历史/进度。
- [ ] iOS 可浏览原生源、阅读、导入本地文件。
- [ ] 三端截图对照通过设计验收。
- [ ] 崩溃率/性能达标。
- [ ] v1.0 安装包可下载。

## 8. 里程碑门禁

每个里程碑结束必须回答：

1. 用户能否独立完成目标路径，不需要开发者解释？
2. 是否有回归测试覆盖关键路径？
3. 性能是否在预算内？
4. 是否引入了新的平台分叉？为什么？
5. 文档是否更新？
6. 是否删除了本里程碑产生的临时实现？

任一项为否，不进入下一里程碑。

| 插件市场 | 签名/审核/评分，谨慎 |

## 11. 决策点

在 M1 前必须确认：

1. **iOS 最低版本**：18.0（覆盖面）vs 26.0（新 API）。建议 18.0。
2. **桌面扩展**：v1 是否支持 JVM 宿主。建议支持，但作为可选模块。
3. **品牌色**：朱砂 `#B4452F` vs 墨蓝。建议朱砂，辨识度高。
4. **是否内置源**：不内置。只提供导入与示例 fixture。
5. **同步协议**：自有 ZIP + WebDAV，先不做账号体系。

## 12. 结论

路线图的核心不是“多久做完”，而是**每个阶段都能停下来交付一个可用产品**：

- M1 后，它是一个能读一个源的小阅读器；
- M2 后，它是一个能日常使用的本地书库；
- M3 后，它在桌面上真正好用；
- M4 后，它接入了生态；
- M5 后，它跨三端。

即使后续里程碑延期，前面的成果仍然是完整、可用的。
