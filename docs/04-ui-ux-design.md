# 04 · UI/UX 重设计

> **方向修正（2026-10-31）：** 本文为初稿，部分结论已被 [07-架构优先方案](07-architecture-first.md) 与 [08-MD3E 设计系统](08-md3e-design.md) 取代。冲突处以后两者为准。

> **按 08 的修正：** Sumi 视觉方向作废；MD3E 设计系统见 [08-md3e-design.md](08-md3e-design.md)。本文的响应式布局、阅读器交互、无障碍/性能约束仍可参考。

> 设计语言：**Sumi（墨）**。纸张、墨色、留白、一个强调色。
> 目标不是“更炫”，而是让内容更快出现、让操作更少猜测、让三端看起来像同一个产品。

## 1. 设计立场

Kototoro 的界面能力很强，但视觉上存在三个问题：

1. **玻璃/模糊/渐变过多**：封面、顶栏、卡片、底栏都在抢注意力，阅读内容反而退后。
2. **卡片语言不统一**：同一屏可能出现 3 种封面比例、2 种圆角、2 种标题层级。
3. **桌面是“放大的手机”**：底栏、单栏、悬浮按钮在鼠标/键盘环境下效率低。

Miyomu 的立场：

- **内容优先**：封面、标题、正文是主角；chrome 退到背景。
- **一个强调色**：只用一个品牌色表达“当前/主操作”；状态用语义色。
- **纸感而非玻璃**：用暖白/墨黑、细边框、轻 tonal surface；默认不做全屏 blur。
- **自适应而非放大**：桌面有侧栏、双栏、命令面板；平板有列表-详情；手机有底栏和 sheet。
- **克制的动效**：只保留“封面→详情”的共享元素和必要的层级过渡。

**规则**：

- 封面本身是彩色的，所以 UI 表面保持中性；不让主题色和封面打架。
- 动态取色（Android）只应用于 accent 的色相，不改变中性底色；桌面/iOS 使用品牌朱砂。
- 不使用纯白 `#FFFFFF` 作为大背景；减少刺眼。
- 所有文字对比度 ≥ 4.5:1；大字号 ≥ 3:1。

### 2.3 字体

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 40/44（桌面）· 32/36（手机） | 600 | 首页问候/空态 |
| Headline | 28/34 · 24/30 | 600 | 页面标题 |
| Title | 20/28 | 600 | 区块标题/卡片标题 |
| Subtitle | 16/24 | 500 | 作者/来源 |
| Body | 16/26 | 400 | 正文 |
| BodySmall | 14/22 | 400 | 辅助信息 |
| Label | 13/18 | 500 | 按钮/标签 |
| Caption | 12/16 | 400 | 角标/时间 |

- UI 字体：系统 UI 字体（SF Pro / Segoe UI Variable / Roboto / Noto Sans SC）。
- 阅读字体：可选 Serif（Noto Serif SC / Source Han Serif / Georgia），不随包内置 CJK 大字库；按需下载或使用系统字体。
- 数字使用 tabular figures（进度、页码、时间）。
- 中文标题避免过细字重；600 足够。

### 2.4 间距与网格

- 基础单位 4dp。
- 常用：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 手机页面左右 20dp；平板 24dp；桌面 32dp。
- 卡片间距：手机 12dp；桌面 16–20dp。
- 内容最大宽度：阅读正文 720dp；设置页 760dp；书库网格占满。
- 桌面 12 列网格；侧栏 232dp；右栏 360dp。

### 2.5 形状与层次

| Token | 值 | 用途 |
| --- | --- | --- |
| `radiusS` | 8dp | 输入框/小按钮 |
| `radiusM` | 12dp | 卡片/列表项 |
| `radiusL` | 16dp | 大卡片/面板 |
| `radiusXL` | 24dp | Hero/底部 sheet |
| `radiusFull` | 999dp | 药丸/头像 |

- 默认 1dp 边框，颜色 `line`；不使用重阴影。
- 卡片 elevation 0–1；sheet 3；dialog 6。
- 背景与卡片靠色差和边框区分，不靠模糊。

### 2.6 动效

- 微交互：120ms。
- 标准：200ms，`cubic-bezier(0.2, 0.7, 0.2, 1)`。
- 大过渡：300ms。
- 共享元素：封面 → 详情封面，280ms；内容淡入 160ms。
- 页面切换：手机 slide+fade；桌面 fade+scale 0.98→1。
- 支持“减少动态效果”：关闭共享元素/弹簧，仅淡入。
- 不使用持续漂浮/呼吸动画。

## 3. 响应式布局

### 3.1 断点

| 名称 | 宽度 | 典型设备 | 导航 |
| --- | --- | --- | --- |
| Compact | < 600dp | 手机竖屏 | 底部栏（≤5） |
| Medium | 600–839dp | 手机横屏/小平板/折叠 | 导航 rail |
| Expanded | 840–1199dp | 平板/小桌面窗口 | rail + 列表-详情 |
| Large | ≥ 1200dp | 桌面 | 侧栏 + 内容 + 上下文栏 |

### 3.2 导航模型

**手机（Compact）**

```text
┌─────────────────────────────┐
│  Home / Library / ...       │  ← 顶部标题 + 搜索/更多
│                             │
│         content             │
│                             │
├─────────────────────────────┤
│ Home  Library  Browse  Updates  More │
└─────────────────────────────┘
```

- 五个目的地：Home、Library、Browse、Updates、More。
- History / Downloads / Bookmarks 放在 Home 快捷卡与 More。
- 层级页面用 push；详情/阅读器全屏。

**平板（Medium/Expanded）**

```text
┌──────┬──────────────────────┐
│ rail │  list                │
│      │  ────────────────    │
│      │  detail / content    │
└──────┴──────────────────────┘
```

- Library：左列表、右详情（选中后）。
- Browse：左来源、右结果。
- Details：左元数据、右章节。
- 折叠屏：hinge 处留 24dp，避免内容跨折痕。

**桌面（Large）**

```text
┌────────────┬──────────────────────────────┬─────────────┐
│ sidebar    │  content                     │ context     │
│ 232dp      │  max 1280                    │ 360dp       │
│            │                              │             │
│ Home       │  Library                     │  Details    │
│ Library    │  ┌────┐ ┌────┐ ┌────┐        │  cover      │
│ Browse     │  │    │ │    │ │    │        │  metadata   │
│ Updates    │  └────┘ └────┘ └────┘        │  chapters   │
│ History    │                              │             │
│ Downloads  │                              │             │
│ Bookmarks  │                              │             │
│            │                              │             │
│ Settings   │                              │             │
└────────────┴──────────────────────────────┴─────────────┘
```

- 侧栏固定，可折叠为 64dp 图标栏。
- 顶部 command bar：搜索（Cmd/Ctrl+K）、返回/前进、窗口控制（由系统提供）。
- 右侧上下文栏可关闭；在详情页显示元数据/章节，在书库页显示筛选。
- 最小窗口 1024×700；默认 1280×820。

### 3.3 页面骨架

所有页面共享：

```kotlin
Scaffold(
    topBar = { MiyomuTopBar(...) },
    bottomBar = { if (compact) MiyomuBottomBar(...) },
    snackbarHost = { ... },
) { padding ->
    Content(padding)
}
```

- 顶部栏高度 56dp（手机）/64dp（桌面）。
- 状态栏/导航栏 insets 由 `WindowInsets` 处理。
- 内容区 `LazyColumn`/`LazyVerticalGrid` 只允许一层滚动；禁止嵌套同方向滚动。
- 底部操作栏（选择模式）覆盖在导航栏上方，不推动内容。

## 4. 关键页面规格

### 4.1 首页 Home

**目标**：3 秒内让用户继续上次阅读，或发现新章节。

```text
┌────────────────────────────────────┐
│ 晚上好                         ⌕  │
│ 10 月 31 日 · 周五                 │
│                                    │
│ 继续阅读                           │
│ ┌────────────────────────────────┐ │
│ │ [cover]  作品名                │ │
│ │          第 12 话 · 62%        │ │
│ │          ━━━━━━━━━━━░░         │ │
│ │          [继续阅读 →]          │ │
│ └────────────────────────────────┘ │
│                                    │
│ 新章节                    全部 →   │
│ ┌────┐ ┌────┐ ┌────┐              │
│ │    │ │    │ │    │              │
│ └────┘ └────┘ └────┘              │
│                                    │
│ 最近添加                           │
│ ┌────┐ ┌────┐ ┌────┐              │
│ │    │ │    │ │    │              │
│ └────┘ └────┘ └────┘              │
└────────────────────────────────────┘
```

- Hero：优先“最近阅读且未读完”；没有则“最近收藏”；再没有则 onboarding。
- 新章节：最多 5 个，来自更新事件；点击进详情并定位新章节。
- 最近添加：按收藏/导入时间。
- 空态：一张“添加第一个源”卡片 + “导入本地文件”按钮，不显示空网格。
- 下拉刷新：刷新更新与封面；不阻塞首页。
- 桌面：Hero 左、右侧显示“本周统计/快捷入口”；下方 6 列网格。

**组件**：`ContinueReadingCard`、`ContentRail`、`ContentCard`、`SectionHeader`、`EmptyOnboarding`。

### 4.2 书库 Library

**目标**：管理大量收藏，快速筛选、排序、批量操作。

```text
┌────────────────────────────────────┐
│ Library                     ⌕  ⋮   │
│ 128 部作品                         │
│ [All] [Reading] [Unread] [Done] ...│
│ ┌────┐ ┌────┐ ┌────┐              │
│ │    │ │    │ │    │              │
│ └────┘ └────┘ └────┘              │
│ ┌────┐ ┌────┐ ┌────┐              │
│ │    │ │    │ │    │              │
│ └────┘ └────┘ └────┘              │
└────────────────────────────────────┘
```

- 分段 chips：All / Reading / Unread / Completed / Downloaded（可横向滚动）。
- 顶部搜索：本地标题/作者；搜索时显示结果计数。
- 筛选/排序：底部 sheet（手机）/右侧面板（桌面）；组内 OR、组间 AND。
- 卡片：2:3 封面、两行标题、进度条、角标（新章节、已下载、置顶）。
- 列表模式：一行一个，封面 56×80，标题/作者/进度/来源；桌面默认网格，可切列表。
- 多选：长按/右键/复选框进入；顶部栏变“已选 N”；底部操作栏：分类、下载、标为已读、删除、更多。
- 空态：
  - 无收藏：“还没有收藏。去浏览源或导入本地文件。”
  - 筛选为空：“没有匹配的作品。清除筛选。”
  - 离线且无下载：“离线状态下只能阅读已下载内容。”

**桌面双栏**：左侧列表，右侧选中作品详情预览；双击打开详情页；空格预览。

### 4.3 浏览 Browse

**目标**：让“找源”和“用源浏览”都简单。

```text
┌────────────────────────────────────┐
│ Browse                     管理源  │
│ ⌕ 搜索源                           │
│ 已固定                             │
│ [icon] Example Manga   日本語 · 漫画│
│ [icon] Novel World     中文 · 小说  │
│ 全部来源                           │
│ [icon] ...                         │
└────────────────────────────────────┘
```

- 来源按“固定/最近使用/全部”分组；显示图标、名称、语言、类型、启用状态。
- 点击来源 → 来源浏览页：来源头 + 排序/筛选 chips + 结果网格 + 自动加载下一页。
- 来源浏览页支持搜索框（源内搜索）。
- 桌面：左侧来源列表，右侧结果；顶部筛选。
- 来源管理入口：右上角“管理源”，进入设置中的源页。

**来源浏览页**：

```text
┌────────────────────────────────────┐
│ ← [icon] Example Manga       ⋮     │
│ 日本語 · 漫画 · 12 个筛选          │
│ [最新] [热门] [评分]   [筛选 2]    │
│ ┌────┐ ┌────┐ ┌────┐              │
│ │    │ │    │ │    │              │
│ └────┘ └────┘ └────┘              │
│             加载更多…              │
└────────────────────────────────────┘
```

### 4.4 详情 Details

**目标**：一眼看懂“这是什么、读到哪里、下一步做什么”。

**手机**：

```text
┌────────────────────────────────────┐
│ ←                              ⋮   │
│      [大封面 / 渐变底]             │
│                                    │
│ 作品名                             │
│ 作者 · 连载中 · ★ 8.6              │
│ [标签] [标签] [标签]               │
│                                    │
│ ┌────────────────────────────────┐ │
│ │ 继续阅读  第 12 话 · 62%   →   │ │
│ └────────────────────────────────┘ │
│ [书签] [下载] [分享]               │
│                                    │
│ 简介                          展开 │
│ ...                                │
│                                    │
│ 章节  128 话        [排序] [筛选]  │
│ ☑ 第 128 话  2026-10-30   ⋮       │
│ ☐ 第 127 话  2026-10-29   ⋮       │
└────────────────────────────────────┘
```

- 封面背景：取封面主色做低饱和渐变（不是全屏模糊）；顶部栏透明叠加，滚动后变实色。
- 主 CTA 固定在底部（手机），滚动时始终可见；桌面放右栏。
- 章节列表：按卷/分支分组；显示已读/下载/书签状态；点击直接阅读；长按多选。
- 作者/状态/评分/标签：一行一个语义块，避免密集小字。
- 简介默认 4 行，展开全文。
- 相关作品：横向 rail，最多 10 个。
- 桌面：左栏封面+元数据+简介；右栏章节列表（独立滚动）；相关在左栏底部。

### 4.5 更新 Updates

```text
┌────────────────────────────────────┐
│ Updates                   全部已读 │
│ [未读 12] [全部] [按来源]          │
│                                    │
│ 今天                               │
│ ┌────────────────────────────────┐ │
│ │ [cover] 作品名        +3 新章节│ │
│ │ 第 128 话 · 2 小时前           │ │
│ │ [继续阅读]              [移除] │ │
│ └────────────────────────────────┘ │
│                                    │
│ 昨天                               │
│ ...                                │
└────────────────────────────────────┘
```

- 时间轴按本地日期分组（今天/昨天/更早）。
- 每条显示作品、新章节数、最新章节、来源、时间。
- 点击条目：标记“已查看”，进入详情并定位最新章节；不自动标已读。
- “全部已读”：清除红点，保留历史与进度。
- 筛选：未读/全部/按来源/按类型。
- 空态：“订阅的作品还没有新章节。去书库检查更新。”

### 4.6 阅读器 Reader

**目标**：内容占满屏幕，控件随叫随到，进度永不丢。

```text
┌────────────────────────────────────┐
│ ←  作品名 · 第 12 话        ⋮      │  ← 自动隐藏
│                                    │
│                                    │
│              [页面]                │
│                                    │
│                                    │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│ 12 / 32          62%        [☰]    │  ← 自动隐藏
└────────────────────────────────────┘
```

- 默认沉浸：状态栏/导航栏隐藏；单击中部切换 chrome。
- 顶部：返回、标题/章节、更多（书签、跳章、设置、分享）。
- 底部：进度条（章节内页 + 全书百分比）、页码、章节目录按钮。
- 左侧/右侧点击翻页；边缘滑动可关闭（可设置）。
- 双指缩放；双击放大/还原；放大后拖动。
- 选项面板：底部 sheet（手机）/右侧面板（桌面），分“显示/布局/导航”三组。
- 章节目录：从左侧滑出/底部 sheet；当前章高亮；已读/下载标记。
- 跨章：到达章节末自动进入下一章（可关）；显示轻提示。
- 进度保存：页面变化节流 1s；退出/切后台立即保存；恢复时回到 page + offset。
- 阅读器背景：纸白/米色/深灰/纯黑；亮度覆盖；护眼滤镜；OLED 纯黑。
- 桌面：左右方向键、PageUp/PageDown、空格、F 全屏、Esc 退出、+/- 缩放、B 书签。
- 平板：双页/RTL 可选；折叠屏 hinge 分隔。

**阅读模式**：

| 模式 | 说明 |
| --- | --- |
| 单页 | 默认；左右翻页 |
| 双页 | 平板/桌面；宽图独占 |
| 右到左 | 日漫 |
| 纵向连续 | 滚动阅读 |
| 条漫 | 零间隙/可配间隙，宽度适配 |
| 横向连续 | 桌面/平板 |

自动检测：取 30% 处页面，`width * 1.8 < height` 判为条漫；每部作品记住上次模式。

### 4.7 搜索 Search

- 全屏/overlay；顶部输入框自动聚焦；取消返回。
- 输入 300ms 防抖；显示“最近搜索”与“搜索建议”。
- 结果 tabs：全部 / 漫画 / 小说 / 视频；分组按来源。
- 单源搜索：在来源浏览页内搜索，不跳全局。
- 空结果：“没有找到。试试更短的关键词，或换一个源。”
- 桌面：Cmd/Ctrl+K 打开命令面板，输入即搜索；`>` 前缀执行命令。

## 7. iOS 细节

- Compose UI 放在 `UIViewController` 中，SwiftUI 只做 App 生命周期与原生桥。
- 安全区/刘海/动态岛：内容避开；阅读器可延伸到边缘。
- 底部 tab bar 使用共享组件，但保留 iOS 手势：边缘右滑返回。
- 阅读器内禁用边缘返回手势，避免和翻页冲突；用顶部返回。
- Sheet 使用 iOS 风格 detents（中/大），但视觉 token 与 Android/桌面一致。
- 文件：`UIDocumentPickerViewController`；分享：`UIActivityViewController`。
- 播放器：`AVPlayerViewController` 通过 `UIKitView` 嵌入；PiP/AirPlay 由系统提供。
- WebView：`WKWebView` 通过 `UIKitView`；Cookie 同步到 Ktor。
- 触觉：轻/中/重三档；翻页/收藏/下载完成。

## 8. 无障碍

- 触控目标 ≥ 48×48dp；桌面 ≥ 32×32 + 8dp 间距。
- 文字缩放 200% 不截断；卡片标题最多 2 行，超出省略并提供无障碍全文。
- 对比度：正文 4.5:1；大字号 3:1；焦点环 3:1。
- 屏幕阅读器：
  - 封面：`作品名，作者，进度 62%，3 个新章节`。
  - 阅读器图片页：`第 12 页，共 32 页`；按钮有明确 label。
  - 小说：按段落/标题分块，支持逐段朗读。
- 键盘：所有操作可达；焦点顺序符合视觉；`Esc` 关闭浮层。
- 动效：尊重“减少动态效果”；不使用闪烁/自动播放。
- 颜色：状态不只靠颜色，配图标/文字。
- 字幕：视频字幕可调字号/背景；支持系统字幕样式。

## 9. 状态设计

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 骨架屏（封面/标题/行），不用全屏 spinner |
| 下拉刷新 | 顶部细进度条；保留旧内容 |
| 空 | 插画 + 一句解释 + 一个主操作 |
| 错误 | 标题 + 原因 + 重试 + “查看诊断” |
| 离线 | 顶部 banner + 缓存标记；禁用不可用操作 |
| 不支持 | 说明“此平台暂不支持 X”，给出替代方案 |
| 部分失败 | 区块级错误，不影响其他区块 |
| 长列表加载更多 | 底部 loader；失败可点重试 |
| 选择模式 | 顶部计数 + 全选/清除；底部操作栏 |

## 10. 性能约束（UI 侧）

1. **禁止全屏 blur**；如使用透明，最多 1 层，且提供“性能模式”关闭。
2. **禁止嵌套同方向 Lazy**；用单个 LazyColumn + section items。
3. **列表项稳定**：`@Immutable` / `ImmutableList`；key + contentType。
4. **图片按目标尺寸解码**；网格不加载大图。
5. **不在 composition 中做 map/filter/排序**；在 ViewModel 或 `remember` 中做。
6. **滚动状态不在 composition 读取**；用 `derivedStateOf` / `graphicsLayer`。
7. **共享元素只用于封面→详情**；不做大面积 hero 动画。
8. **桌面窗口 resize 不重建整页**；用 `BoxWithConstraints` 的局部布局。
9. **阅读器预取可关**；低内存设备自动降级。
10. **每帧预算 16.6ms**；CI 跑 Macrobenchmark + 帧率采样。

## 11. 原型（暂缓）

原型工作已暂停，原因：

- 当前首先要确认的是数据契约、模块边界和初始化顺序，而不是像素；
- 没有真实 Compose 组件与资源约束时，HTML 原型容易产生无法落地的视觉承诺；
- 等 M1 纵切跑通后，直接用 Compose Preview + 真机截图做设计评审，效率更高。

已有一份草稿 `design/archive/sumi-prototype.html`，仅作为配色/密度参考，不作为验收依据。
