## 1. 当前能力

- **本地漫画**：目录、ZIP/CBZ；详情/阅读/续读；章节已读/书签持久化（`entry_chapter`）。
- **本地视频**：单文件/多集目录/季目录；逐集进度、音轨/字幕轨、倍速、双击/手势、下一集/自动连播；封面与详情。
- **在线漫画**：源仓库索引 → 安装/更新 → QuickJS 运行时 → 浏览/全局搜索/详情/阅读；已读/书签、下载队列、离线阅读。
- **在线 anime**：自有 `AnimeSource` JS 格式（search/detail/resolve），苹果CMS 模板 + omofun 真站；resolve 的防盗链 headers 直达播放器；解析缓存。
- **书架与数据**：分类 Tab 与批量编辑、更新检查、历史/更新 Tab、备份导出/恢复、WebDAV（Basic）同步。
- **设置与外观**：Aniyomi 主题/阅读器主题、动态色（Android Monet）、阅读/播放/下载/数据/弹幕设置。
- **播放器与弹幕**：mediamp（Android ExoPlayer / 桌面 MPV）、亮度/音量手势、长按 2x、弹幕（弹弹play，自配凭据）。
- **本地库**：Android 支持 SAF 选择库目录（持久权限）。

## 4. 已知缺口（当前优先级）

1. **平台发布**：桌面 jpackage（msi/dmg）未配置；Windows 端 MPV 播放与安装包未实机验证；iOS 生产壳/AVKit 未开始。
2. **播放器**：音轨/字幕选择不持久化；无锁屏/画中画/MediaSession；外挂字幕受 mediamp 0.5.3 限制（两个后端都不应用 `MediaExtraFiles`），需上游贡献或自研。
3. **本地内容**：7Z/PDF/EPUB/TXT 加载器与小说阅读器未开始；本地视频混合目录（直接视频 + 季子目录）只取直接视频；本地剧集书签未持久化（已看由进度推导）。
4. **在线源**：第一波为 omofun + 苹果CMS 模板；canary 需手动 `-Pcanary`，未定时跑；站点改版维护由项目承担；tracker 未实现；WebDAV 仅 Basic 认证；弹幕需用户自配弹弹play 凭据。
5. **CI**：`download`/`danmaku` 测试未进 CI；无 Windows job；无安装包冒烟。
6. **Linux 桌面**：无视频（MPV Linux 运行时 GPL-3.0，ADR-0012 方案 A）。

## 5. 并行开发规则（Windows + macOS，goal 模式）

- **单一 schema owner**：同一时间只允许一个分支修改 `shared/data/schemas`、`shared/model`、`MiyomuGraph`/`MiyomuApp`/`HomeScreen` 接线；其他分支 rebase 后接入。
- 每个 goal 一个短分支（`feat/...`），基于最新 `main`；完成或受阻时 push；**夜间不合并 main**，早上按 CI 结果 squash merge。
- 建议分工：数据/内容侧（`shared/data`、源、下载、备份、小说）与平台/播放侧（`desktopApp`、`shared/player`、`.github`、Windows 证据）两条流水线；`shared/ui` 按屏分工。
- goal 时间窗 23:00–09:00；08:45 停止新改动、push、写 `docs/goals/<id>.md`；单 goal 软预算约 15M tokens，同一错误 3 次不通过即停止报告。
- 证据文件名带平台/切片前缀（`win-...`、`c3-...`），避免两台机器改同一张图。
- 旧的两设备队列（A1 在线书架 / A2 章节表 / A3 下载）已被 C3/D 完成，按下面的新队列重排。
