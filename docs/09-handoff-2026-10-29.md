关键替换（详见 ADR-0011 替换表）：

- **Injekt DI → 构造注入**：`app.miyomu.ui.MiyomuGraph` 由平台入口装配，逐层显式传参；ScreenModel 构造函数显式化。
- **Voyager**：采用 Aniyomi 自己的 fork `cafe.adriel.voyager:*:2.2.21-1.10.3`（Maven Central，**带 jvm/desktop 目标**，已验证 `.module` variants）。
- **moko-resources 0.26.0**：唯一同时满足「KMP-first Android 插件（`android-kmp-library`）」和「字段式生成 API（`MR.strings.x`）」的版本。0.24.5 在 AGP9 KMP 插件下报 `androidSourceSetName has no value`；0.27.1 把生成 API 改成扩展属性，会让逐字复制的 Aniyomi 代码全部编译失败。**升级前必须评估迁移成本。**
- **BackHandler**：`org.jetbrains.compose.ui:ui-backhandler`（`androidx.activity.compose.BackHandler` 在桌面不可用）。
- **Android 专属 API → expect/actual**：`ImeVisibility`（android: `WindowInsets.isImeVisible`；jvm: `false`）、`SystemGestureExclusion`（android 真实现；jvm 恒等）。
- **`LocalConfiguration`/`Configuration` → `LocalWindowInfo.current.containerSize`**（已在 `AdaptiveSheet.kt` 落地，其余文件待办，见第 5 节）。
- **`@ReadOnlyComposable` 移除**：moko 的 `stringResource` 不是 `@ReadOnlyComposable`，凡是调用它的 composable 必须去掉该注解。
- **coil3 不用 BOM**：BOM 在 KMP 下无法解析 `io.coil-kt.coil3:coil`，改用逐 artifact `version.ref`。

## 10. Git 推送配置（本机环境问题，勿再踩）

现象：`git push` 报 `remote: No anonymous write access. fatal: Authentication failed for 'https://gh-proxy.com/https://github.com/Yuki-alice/miyomu.git/'`。

根因：`~/.gitconfig` 有一条全局镜像规则

```
url.https://gh-proxy.com/https://github.com/.insteadOf = https://github.com/
```

它把所有 `https://github.com/` 的地址改写成 gh-proxy 镜像。该镜像**只允许匿名读取**，因此 `fetch`/`ls-remote` 正常，`push` 必然失败——和凭据是否存在无关（GitHub 的凭据在凭据管理器里是有的）。

解决方案：再加一条只作用于推送的全局规则，让 push 走直连：

```bash
git config --global "url.https://github.com:443/.pushInsteadOf" "https://github.com/"
```

`pushInsteadOf` 只影响推送 URL，`fetch` 仍然走镜像，两者互不干扰。`github.com:443` 带端口的形式不会再被上面的 `insteadOf` 规则二次匹配，所以能绕开改写。配好后 `git remote -v` 会显示 push 地址为 `https://github.com:443/Yuki-alice/miyomu.git`，此时直接 `git push` 即可。

注意：这个规则是**全局**的，会影响本机所有指向 github.com 的仓库；但方向是对的（读走镜像、写走直连），一般不需要清理。仓库级的 `remote.origin.pushurl` 临时方案已删除，不要再加回去——它会和全局规则叠加，增加困惑。
